# One-Line Office Joke: 24-Hour Sprint

A one-line joke about office life, written by a pure-stdlib Python program for the make.fun bounty **One-Line Office Joke: 24-Hour Sprint**.

> The office printer only jams on the document marked urgent — I’m convinced it reads the subject line before deciding to jam.

Run `python3 main.py` — it writes the joke (one line, 124 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–200 characters, single line, no trailing newline).
